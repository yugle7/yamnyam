# Project Rules

- Use only vanilla HTML, CSS, and JavaScript. No external dependencies.
- Keep all application logic in the existing `script.js`.
- Do not create additional JS files, modules, or use `import`/`export`.
- Do not add libraries, frameworks, build tools, package managers, `package.json`, lock files, or `node_modules`.
- Preserve the existing project structure.

- Prefer the simplest solution with minimal code and concepts.
- Avoid duplicated logic and unnecessary abstractions.
- Avoid redundant checks, excessive validation, defensive programming, and unnecessary error handling.
- Follow the existing coding style. Keep code readable.

- Inspect existing code and `git diff` before editing.
- Make only changes required by the task.
- Preserve existing behavior and unrelated user changes.
- Do not perform unrelated refactoring or add unrequested features.
- Do not delete files unless they are confirmed to be unnecessary.

- Review the final `git diff` before finishing.
- Verify that all application logic remains in `script.js`.
- Report changed files and the checks actually performed.
- If a requirement conflicts with these rules, explain why and choose the simplest compliant solution.
